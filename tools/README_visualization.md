# Analysis Results Visualization Script

Comprehensive visualization tool for checkpoint analysis results generated by `checkpoint_arch_analysis.py`.

## Quick Start

```bash
# Visualize results from default analysis directory
python -m tools.visualize_analysis_results --analysis_dir analysis

# Specify custom output directory
python -m tools.visualize_analysis_results --analysis_dir analysis --output_dir custom_figures
```

## What It Does

The script automatically loads all CSV files from the `analysis/tables/` directory and generates comprehensive visualizations:

### 1. Parameter Metrics Overview (`parameter_metrics_overview.png`)
- Distribution plots for relative delta, cosine similarity, and spectral drift
- Bar charts comparing metrics by layer type
- Top 20 most changed parameters
- Scatter plots showing relationships between metrics
- Summary statistics table

### 2. Per-Layer CKA/SVCCA Comprehensive (`per_layer_cka_svcca_comprehensive.png`)
- Line plots showing CKA/SVCCA trends across layers
- Bar charts grouped by layer category (Early/Middle/Late blocks)
- Difference plots comparing Direct-FT vs POMP-FT
- CKA vs SVCCA correlation plots

### 3. Block-Wise Analysis (`block_wise_analysis.png`)
- Heatmaps showing parameter changes by block and submodule
- Average relative delta per block across comparisons
- Detailed submodule-level analysis

### 4. Comprehensive Dashboard (`comprehensive_dashboard.png`)
- All-in-one dashboard with:
  - Parameter change summaries
  - CKA/SVCCA comparisons
  - Layer-wise progression plots
  - Top changed layers
  - Summary statistics

## Output Files

All visualizations are saved as both PNG (for viewing) and PDF (for papers):

- `parameter_metrics_overview.png/pdf`
- `per_layer_cka_svcca_comprehensive.png/pdf`
- `block_wise_analysis.png/pdf`
- `comprehensive_dashboard.png/pdf`

## Requirements

- pandas
- numpy
- matplotlib
- seaborn

## Usage Examples

### Basic Usage
```bash
python -m tools.visualize_analysis_results
```

### Custom Directory
```bash
python -m tools.visualize_analysis_results \
    --analysis_dir /path/to/analysis \
    --output_dir /path/to/output/figures
```

## Features

- **Automatic Detection**: Automatically finds and loads all CSV files
- **Comprehensive Coverage**: Visualizes all available metrics
- **Publication Quality**: High-resolution PNG and PDF outputs
- **Flexible**: Works with any analysis directory structure
- **Error Handling**: Gracefully handles missing data

## Integration

This script is designed to work seamlessly with `checkpoint_arch_analysis.py`:

1. Run analysis: `python -m tools.checkpoint_arch_analysis ...`
2. Generate visualizations: `python -m tools.visualize_analysis_results --analysis_dir analysis`

The script will automatically discover and visualize all generated CSV files.
